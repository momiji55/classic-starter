
# CSS 余白（上下スペーシング）ルール

classic-starter における、要素の上下方向の余白の取り方を定めたルールです。
このテーマを土台に新規案件を始める際は、本ルールに沿って余白を組みます。

## 基本方針

| 項目 | 決定 |
|---|---|
| 方向 | **下方向に統一**（`margin-bottom` のみを使う） |
| 単位 | **`rem`**（ルートフォントサイズ基準） |
| 値の刻み | **8px ベースのスケール**を CSS 変数で定義し、`var()` で参照 |

### なぜこの方針か

- **下方向統一** … ブラウザ・WordPress 出力の既定が `margin-bottom` 中心。流れに逆らわず破綻しにくい。「上から積み上げる」感覚に合う。
- **rem** … ユーザーのブラウザ文字サイズ設定に余白も追従するため、アクセシビリティで有利。多案件で再利用するボイラープレートとして汎用性が高い。
- **8px スケール** … 8 は約数が多く半分・倍が作りやすい。デザインツール・UI フレームワークの事実上の標準。

## スペーシングスケール

`:root` に以下の CSS 変数を定義し、余白は必ずこの中から選ぶ。
（`tokens.css` の `:root` で定義する）

```css
:root {
  --space-1: 0.25rem; /*  4px */
  --space-2: 0.5rem;  /*  8px */
  --space-3: 0.75rem; /* 12px */
  --space-4: 1rem;    /* 16px */
  --space-6: 1.5rem;  /* 24px */
  --space-8: 2rem;    /* 32px */
  --space-12: 3rem;   /* 48px */
  --space-16: 4rem;   /* 64px */
}
```

- 変数名の数字は **8px を 1 単位とした倍率ではなく、`0.25rem`（4px）刻みの番号**。`--space-6` = `6 × 4px` = 24px と読む。
- 案件ごとに余白トーンを変えたい場合は、`:root` の数値だけを調整すれば全体に一括で反映される。

### 用途の目安

| 変数 | px | 主な用途 |
|---|---|---|
| `--space-2` | 8px | ラベルと値の間など細かい余白 |
| `--space-3` | 12px | 小要素間 |
| `--space-4` | 16px | 標準の要素間 |
| `--space-6` | 24px | 本文ブロック間 |
| `--space-8` | 32px | 部品の中の大きめの区切り（コメント欄の項目どうし、本文の h3・h4 の前） |
| `--space-12` | 48px | `--gap-l` の実体。部品の内側で大きく空けたい時（パターンの padding 等） |
| `--space-16` | 64px | md 以上の `--gap-l` の実体。単独で使うことはほぼない |

## 余白の2層（スケールと「間」）

余白は次の2層で考える。**どちらを使うかは「画面幅で広がってほしいか」で決める。**

### 1. 部品の内側・部品の中 → `--space-*`（固定）

`padding`、見出しと本文の間、段落どうし、ラベルと値の間、フォームの行間など。画面幅が変わっても同じ値でよい余白は、スケールから直接選ぶ。テーマの余白の大半はこの層。

### 2. 部品どうし・まとまりの間 → `--gap-*`（md 以上で一段広がる）

1px の線の周りや、ページの骨格にあたる間隔。広い画面では窮屈に見えるため、md 以上で一段広げる。

| 変数 | md 未満 | md 以上 | 用途 |
|---|---|---|---|
| `--gap-m` | 24px（`--space-6`） | 32px（`--space-8`） | 要素の間（記事一覧の区切り線の上下、ウィジェットのカードどうし、記事のタイトル → 本文、カテゴリ・タグ → 前後の記事、ヘッダー → パンくず 等） |
| `--gap-l` | 48px（`--space-12`） | 64px（`--space-16`） | まとまりの間（ヘッダー・パンくずと本文、本文とサイドバー・フッター、本文の h2 の前、記事の本文 → カテゴリ・タグ、記事 → コメント欄） |

- 値は `tokens.css` の `:root` で定義し、md 以上の値は同じファイル末尾の `@media` で上書きする。
- **段階の差をはっきり付ける**（例: 記事の中は `--space-3`、記事の区切り線の上下は `--gap-m`、記事とコメント欄の間は `--gap-l`）。差が小さいとまとまりが崩れる。
- 以前あった `--gap-s` は `--space-3` と同じ値で md 以上でも変わらず、別名を持つ意味が無かったため廃止した。要素の中の小さな余白はスケールから直接選ぶ。

## 適用ルール

### 1. 余白は `margin-bottom` で付ける

```css
/* OK */
.post-item { margin-bottom: var(--space-6); }

/* NG: 上方向は使わない */
.post-item { margin-top: var(--space-6); }
```

### 2. 親要素の末尾は打ち消す

下方向統一では最後の子要素の余白が親からはみ出るため、ラッパー要素では末尾を 0 にする。

```css
.post-item-content > *:last-child {
  margin-bottom: 0;
}
```

### 3. 見出しも下方向のみで表現する

「見出しの前を広げたい」場合でも `margin-top` は使わず、直前要素の `margin-bottom` で間隔を作る。
見出し自体は下に小さめの余白を持たせ、後続の本文と近づける。

```css
/* 見出し: 下に小さめ */
.entry-content :is(h2, h3, h4) {
  margin-bottom: var(--space-3);
}
```

### 4. 本文テキスト間の余白

投稿・固定ページの本文（`content.css`）の要素（`p`, `ul`, `ol`, `blockquote`, `pre`, `table` と、本文直下のブロック）は
`--space-6`（24px）を基準にする。本文の行間（1.8）に合わせ、段落の切れ目が行の間と区別できるよう、1行の高さに近い量を空ける。
一覧の抜粋など、本文以外の短い文章（`common.css`）は `--space-4`（16px）のまま。

```css
:is(.entry-content, .wp-block-post-content) :is(p, ul, ol, blockquote, pre, table) {
  margin-bottom: var(--space-6);
}
```

## 整合性に関する注意（body のフォントサイズ）

`rem` の基準は `<html>`（ルート）であり、`html` に `font-size` を指定していなければ
ブラウザ既定の 16px が `1rem` になる。

一方で本文の文字サイズを `body { font-size: 16px; }` と **px で固定すると、本文だけが
ユーザーの文字サイズ設定を無視する**ことになる。余白を rem で組むなら整合させるため、
本文も相対指定にするのが望ましい。

```css
body {
  font-size: 1rem; /* px 固定をやめてユーザー設定に追従させる */
}
```

## やってはいけないこと

- `margin-top` で要素間の余白を作る（方向が混在する）
- スケール外の値（`13px`, `22px`, `30px` など）を直接書く
- 余白に `px` を新規で使う（既存の `px` も順次 `rem` / 変数へ置き換える）

## 適用範囲

本ルールは **要素の上下方向の余白（縦のリズム）** を対象とする。
左右の余白・コンポーネント内部の `padding`・`gap` は別途、同じスケール（`--space-*`）の
利用を推奨するが、本ルールの強制対象ではない。
