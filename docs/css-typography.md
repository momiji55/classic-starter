
# CSS フォントサイズ ルール

classic-starter における、文字サイズ（`font-size`）の扱い方を定めたルールです。
このテーマを土台に新規案件を始める際は、本ルールに沿って文字サイズを組みます。

## 基本方針

| 項目 | 決定 |
|---|---|
| 単位 | **`rem`**（px 固定は使わない） |
| 定義場所 | `tokens.css` の `:root` に `--text-*` トークンで定義 |
| 参照方法 | 各セレクタでは **`var(--text-*)` で参照**する |
| 例外 | 親基準で相対変化させたい箇所のみ `em`（例: コードの `0.9em`）。`inherit` も可 |

### なぜこの方針か

- **rem に統一** … px 固定はユーザーのブラウザ文字サイズ設定を無視してしまう。余白（`--space-*`）が rem 基準なので、文字サイズも揃えると拡大縮小時に破綻しない。アクセシビリティで有利。
- **タイプスケール化** … 使ってよいサイズを限定することで、文字サイズの乱立を防ぎ一貫性を保つ。案件ごとのトーン調整も `:root` だけで済む。
- **`em` の例外** … インラインコードなど「親の文字サイズに対して少し小さく」したい箇所は、絶対値より相対指定（`em`）が適切なため対象外とする。

## タイプスケール

`:root` に以下を定義し、文字サイズは必ずこの中から選ぶ。

```css
:root {
  /* フォントサイズ（タイプスケール / rem 基準） */
  --text-2xs: 0.75rem;  /* 12px: 英字のラベル・小さなリンク、数字だけの補足（日付）、アイコンボタンのラベル */
  --text-xs: 0.875rem;  /* 14px: 本文より一段小さい UI の文字（メタ・キャプション・フッター・サイドバー・ナビ・フォームのラベル） */
  --text-base: 1rem;    /* 16px: 本文 */
  --text-lg: 1.125rem;  /* 18px: リード文 */
  --text-xl: 1.25rem;   /* 20px: 小見出し */
  --text-2xl: 1.5rem;   /* 24px: 中見出し（記事タイトルより一段下げたい見出し） */
  --text-3xl: 1.75rem;  /* 28px: 大見出し（記事・固定ページのタイトル） */
  --text-4xl: 2.5rem;   /* 40px: 表示用の大見出し（404 の数字等） */
}
```

- `1rem` = ルート（`<html>`）の文字サイズ。`html` に `font-size` を指定していなければブラウザ既定 16px。
- **画面幅に連動させて伸縮させない**（`clamp()` + `vw` の可変サイズは使わない）。画面幅で大きさを変えたい時は、ブレークポイント（`docs/css-responsive.md`）の `@media` でスケールの値を一段ずつ切り替える。`vw` 連動は実際に大きさが変わる画面幅が中途半端な範囲になりやすく、狭めた PC だけ小さくなる等の分かりにくい動きになるため。

### 用途の目安

| 変数 | px 目安 | 主な用途 |
|---|---|---|
| `--text-2xs` | 12px | 英字のラベル（404 の「Page Not Found」、検索結果・アーカイブの見出しのラベル、投稿詳細の前後の記事の「Prev」「Next」）と小さなリンク（一覧の「続きを読む」、ページ送り、コメントの「返信」）。大文字のラベルは同じ大きさでも小文字や日本語より大きく見えるため、`--text-xs` より一段下げる。数字だけのサイドバーの日付（最新記事のカード）、ヘッダーのアイコンボタンのラベルにも使う。日本語の長い文には使わない |
| `--text-xs` | 14px | 本文より一段小さい UI の文字。キャプション、フッター、サイドバー、ヘッダーのナビ、パンくず、記事メタ情報、ページ送りの番号、フォームのラベル、ヘッダーの上の帯のサイト説明文 |
| `--text-base` | 16px | 本文（`body`）、本文の h4、md 未満の記事一覧のタイトル、ボタン（`.button`） |
| `--text-lg` | 18px | リード文、本文の h3、md 以上の記事一覧のタイトル、最新記事のカードの見出し |
| `--text-xl` | 20px | 小さめの見出し、本文の h2、記事が無い時の見出し、コメント欄の見出し |
| `--text-2xl` | 24px | サイトタイトル、一覧・検索結果の見出し。中見出し。記事タイトル（`--text-3xl`）より一段下げたい見出し（パターン「Call to action」の見出し等） |
| `--text-3xl` | 28px | 大見出し（記事・固定ページのタイトル）。ミニマルな見た目に合わせ、太字でも強すぎない大きさにしている |
| `--text-4xl` | 40px | 表示用の大見出し（404 の数字等。ほかに要素が少なく、文字そのものを大きく見せたいページ用） |

### フォント

| 変数 | 主な用途 |
|---|---|
| `--font-base` | `body` のフォント。フロントの `common.css` とエディターの `editor-style.css` で共有する |
| `--font-mono` | コード（`pre` / `code`）の等幅フォント。本文（`content.css`）とウィジェット（`common.css`）で共有する |

### 字間（letter-spacing）

字間を広げるのは小さなラベル的な文字だけ（ボタン・カテゴリ・タグ・ナビ・ラベル）。値は直書きせずトークンを参照する。

| 変数 | 値 | 主な用途 |
|---|---|---|
| `--letter-spacing-wide` | `0.1em` | ラベル全般（「Read more」「Prev」「Next」、ボタン、カテゴリ・タグ、ナビ）。ラベルの下線を最後の文字に合わせて短くする `calc()` でも使う |
| `--letter-spacing-wider` | `0.2em` | パターンの見出しの上に置く小さなラベル（`.cta-label` / `.latest-card-label`） |

## 適用ルール

### 1. 文字サイズは必ず変数で参照する

```css
/* OK */
.footer-copyright { font-size: var(--text-xs); }

/* NG: px / 生の値を直書きしない */
.footer-copyright { font-size: 14px; }
```

### 2. px は使わない

新規の `font-size` に px を使わない。既存の px も rem 相当のトークンへ置き換える
（16px 基準では `14px = 0.875rem`、`18px = 1.125rem`、`28px = 1.75rem`、`40px = 2.5rem` と等価で見た目は変わらない）。

### 3. 相対指定が適切な箇所は `em` を使う

インラインコードのように「親に対して少し小さく」したい場合は、トークンではなく `em` を使う。

```css
.post-item-content code {
  font-size: 0.9em; /* 親の文字サイズに追従させる */
}
```

### 4. 案件ごとの調整は `:root` だけ編集する

文字サイズのトーンを変える際は各セレクタを触らず、`:root` のトークン値のみ変更する。
ただし、エディターで選べる大きさ（下記）は、`functions.php` の `size` も同じ値に直す。

### 5. エディターで選べる文字サイズはタイプスケールに絞る

ブロックエディターの文字サイズは `functions.php` の `editor-font-sizes` で、本文向けの次の5段階だけにしている。数値の直接入力と WordPress 標準の文字サイズは無効にしている。

| 文字サイズ（訳） | slug | トークン |
|---|---|---|
| Small（小） | `xs` | `--text-xs` |
| Normal（標準） | `base` | `--text-base` |
| Large（大） | `lg` | `--text-lg` |
| Extra large（特大） | `xl` | `--text-xl` |
| Huge（最大） | `2-xl` | `--text-2xl` |

- ラベル用（`--text-2xs`）は本文で使うと読みにくいため、タイトル・表示用（`--text-3xl` / `--text-4xl`）は本文の見出しの段階を崩すため入れない。
- slug は WordPress がクラス名・変数名にする時に数字と英字の間へハイフンを入れるため、`2xl` ではなく `2-xl` にしている（`.has-2-xl-font-size`）。
- 色と同じく、`tokens.css` の `body` で `--wp--preset--font-size--{slug}` をトークンに差し替えている。

## やってはいけないこと

- `font-size` に px を新規で使う
- スケール外の値（`13px`, `17px` など）を直接書く
- `letter-spacing` の値（`0.1em` 等）を直接書く（トークンを参照する）
- 用途と異なるトークンを流用する
